# SFT (Supervised Fine-Tuning) 강의 스크립트

## 1. 서론

**SFT** (**Supervised Fine-Tuning, 지도학습 기반 미세조정**)에 대해
알아보겠습니다.
SFT는 대규모 언어모델(LLM)의 능력을 특정 태스크에 맞게 조정하는 가장
대표적인 방법으로, 최근 ChatGPT, GPT-4, LLaMA 계열 모델에도 적용된 핵심
기법입니다.

------------------------------------------------------------------------

## 2. SFT의 정의

-   **Supervised Fine-Tuning** (**SFT**)은 **사람이 레이블링한 데이터**(**지도
    데이터**)를 활용하여 Pretraining된 모델을 특정 태스크에 맞게
    학습시키는 과정입니다.
-   즉, 모델이 **"주어진 입력 → 정답 출력"** 관계를 직접 배우도록 하는
    방식입니다.

예:
- 입력: "Translate 'Hello' into Korean."
- 출력: "안녕하세요."
이런 쌍을 대규모로 학습시키는 것이 SFT입니다.

------------------------------------------------------------------------

## 3. SFT의 특징

1.  **지도 데이터 필요**: 사람이 직접 만든 고품질 데이터셋을 사용.
2.  **태스크 특화**: 질의응답, 요약, 번역, 분류 등 특정 작업에 최적화.
3.  **효율성**: Pretraining 덕분에 적은 데이터로도 높은 성능 달성.
4.  **기반 모델 성능 활용**: Pretraining에서 학습한 범용 지식을 바탕으로
    태스크에 맞게 조정.

------------------------------------------------------------------------

## 4. SFT의 수식적 이해

모델의 출력 확률 분포를 ($P_{heta}(y|x)$)라고 할 때,
SFT는 **지도 데이터셋** ((x, y))에 대해 손실 함수 (L)을 최소화하는
방식으로 진행됩니다.

$$ L(heta) = - \sum_{(x,y)} \log P_{heta}(y|x) $$

이는 모델이 주어진 입력 (x)에 대해 정답 (y)를 정확히 예측하도록
파라미터 (heta)를 조정하는 과정입니다.

------------------------------------------------------------------------

## 5. SFT의 예시 활용

-   **챗봇 학습**: 사람이 만든 질문-답변 쌍으로 모델을 학습 → 더
    자연스러운 대화 가능.
-   **문서 요약**: 기사-요약문 데이터셋으로 학습 → 자동 요약 시스템
    구현.
-   **법률/의학 등 특화 모델**: 전문 지식이 담긴 QA 데이터를 활용 → 특정
    도메인에 강한 모델 완성.

------------------------------------------------------------------------

## 6. Pretraining과의 차이

  구분    | Pretraining                      | SFT
  -------- | -------------------------------- | --------------------
  데이터   | 대규모 비지도(웹, 위키, 책 등)   | 소규모 지도 데이터
  목적     | 범용 언어 지식 습득              | 특정 태스크 최적화
  비용     | 매우 큼 (수천 GPU)               | 비교적 적음
  출력     | 범용적 모델                      | 태스크 맞춤형 모델

------------------------------------------------------------------------

## 7. 결론

-   SFT는 **대규모 모델을 실제 활용 가능한 태스크 특화 모델로 만드는
    핵심 과정**입니다.
-   Pretraining으로 쌓은 기초 체력을 바탕으로, SFT를 통해 원하는 작업에
    맞게 모델을 세밀하게 조정할 수 있습니다.
-   따라서 오늘날의 LLM 서비스는 대부분 **Pretraining → SFT → 추가적인
    RLHF/PEFT** 순서로 발전합니다.
