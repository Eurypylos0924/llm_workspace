# Pretraining과 Finetuning

## 1. 서론

인공지능 모델을 훈련시키는 핵심 과정인
**Pretraining(사전학습)**과 **Finetuning(미세조정)**에 대해
알아보겠습니다.
이 두 개념은 대규모 언어모델(LLM)과 같은 현대 AI 모델의 성능을 이해하고
활용하는 데 매우 중요한 기초입니다.

------------------------------------------------------------------------

## 2. Pretraining (사전학습)

### 정의

-   Pretraining은 대규모 비지도 데이터셋을 활용하여 모델이 **언어의
    일반적 패턴과 지식을 학습**하는 단계입니다.
-   주로 **다음 단어 예측**(Next Token Prediction) 또는 **마스킹된 단어
    복원**(Masked Language Modeling) 방식으로 학습합니다.

### 특징

-   **대규모 데이터셋**: 인터넷, 책, 논문, 위키백과 등 수십억 문장
    규모의 데이터.
-   **범용적 능력**: 문법, 의미, 상식, 추론 등을 전반적으로 학습.
-   **고비용 연산**: 수천 개의 GPU/TPU가 수주\~수개월 동안 사용됨.

### 예시

GPT, BERT, LLaMA, DeepSeek 등의 모델들은 모두 Pretraining을 거쳐 **범용
언어 능력**을 획득합니다.

------------------------------------------------------------------------

## 3. Finetuning (미세조정)

### 정의

-   Finetuning은 Pretraining으로 학습된 모델을 **특정 도메인 또는 특정
    태스크에 맞게 조정**하는 과정입니다.
-   예: 법률 문서 요약, 의학 진단 질의응답, 금융 데이터 분석 등.

### 특징

-   **소규모 데이터셋**: 수천\~수십만 개의 태스크 특화 데이터.
-   **빠른 학습**: Pretraining에 비해 훨씬 적은 자원과 시간 필요.
-   **맞춤형 성능**: 특정 분야에서 더 높은 정확도와 유용성을 보장.

### 기법

-   Full Finetuning: 전체 모델 파라미터를 업데이트 → 고비용, 성능
    극대화.
-   Parameter Efficient Fine-Tuning (PEFT): LoRA, Prefix Tuning 등 일부
    파라미터만 학습 → 효율적.

------------------------------------------------------------------------

## 4. Pretraining vs Finetuning 비교

  구분       | Pretraining           | Finetuning
  ----------- | --------------------- | --------------------
  목적       | 일반적 언어/지식 학습   | 특정 태스크 적응
  데이터      | 초대규모 범용 데이터    | 소규모 특화 데이터
  자원 소모   | 매우 큼 (수천 GPU)      | 비교적 적음
  결과        | 범용적 모델             | 맞춤형 모델

------------------------------------------------------------------------

## 5. 결론

-   Pretraining은 **기초 체력**을 키우는 과정이고, Finetuning은 **특정
    종목 훈련**을 하는 과정이라고 볼 수 있습니다.
-   따라서, 두 과정은 상호 보완적이며, 오늘날 대부분의 AI 시스템은
    **Pretraining → Finetuning** 파이프라인을 통해 구축됩니다.
